## 📂 Featured Repository

### [powershell-enterprise-toolkit](https://github.com/evgenybl/powershell-enterprise-toolkit)
A collection of production-grade PowerShell scripts built from real enterprise IT work.
Covers the full Microsoft stack: Active Directory, Exchange Online, Entra ID, Microsoft 365, and Group Policy.

**Scripts included:**
- `Invoke-EmployeeOffboarding` - Full AD + M365 offboarding in one run
- `Find-StaleAccounts` - Cross-checks AD and Exchange Online to detect inactive accounts
- `Send-PasswordExpiryNotification` - Automated HTML email reminders with configurable thresholds
- `Export-ADUserAttributes` - Bulk user export by EmployeeID for HR reconciliation
- `Convert-RegistryToGPO` - Converts .reg files to Group Policy Preferences XML
- `Get-M365LicenseReport` - License usage, waste detection, and cost estimation
- `Invoke-ConditionalAccessAudit` - Security gap analysis across all CA policies
- `Get-EntraGuestReport` - Risk-rated guest user inventory with privilege detection
- `Set-BulkUserOnboarding` - End-to-end onboarding from CSV: AD + Entra + license + welcome email
- `Get-MailboxPermissionReport` - Full Exchange Online delegation audit
